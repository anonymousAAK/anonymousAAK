## About

I build systems at the seams between fields. An AI agent, a financial market, a physical process, and a programming language are the same kind of object to me: a thing with state, dynamics, failure modes, and an interface — all of which can be modeled, instrumented, and broken on purpose.

Right now that means shipping real things: **[aastf](https://github.com/anonymousAAK/aastf)**, an agentic-AI security framework on PyPI; **[aiguard](https://github.com/anonymousAAK/aiguard)**, a Rust security harness for CLI coding agents on crates.io; **[qufin](https://github.com/anonymousAAK/qufin)**, a quantum-finance toolkit with 2,499 tests; **[plotkit](https://github.com/anonymousAAK/plotrs)**, a from-scratch Rust plotting library; and **[FoldCopilot](https://github.com/anonymousAAK/FoldCopilot)**, an MCP server that catches confidently-wrong protein-structure predictions. The rest of the account shows where this came from — a NASA Kepler pipeline, my own interpreted language, a four-language algorithms curriculum.

If a problem requires translating between physics, finance, machine learning, and production code — that's the kind of problem I want.

## Background

- **MBA candidate — IIM Raipur, PGP Class of 2027.**
- **BSc (Hons.) Physics** — classical mechanics, statistical physics, computational methods.
- **Published research** — *Realizing a Fully Functional CPU Using Multi-Layer Perceptrons*, IJARIIT, Vol. 11, Issue 1, pp. 248–256 (Feb 2025), ISSN 2454-132X. The paper introduces **IC 616 Ultra-MLP**, a fully perceptron-based CPU: arrays of threshold units that, with the right weights and biases, implement standard computing tasks — pipeline, memory hierarchy, and on-chip training included.
- **Co-founder — AI research lab.** Led work on large-parameter simulation models, including a multi-country macroeconomic simulation engine. (Most of that work lives outside this account.)
- **Quant research interests** — implied volatility surfaces, SVI/SABR calibration, HMM regime detection, portfolio optimization, Monte Carlo VaR.

## Featured Work

Ranked by what they prove, not language stack. Five shipped projects across security, finance, scientific computing, and systems — plus the foundations underneath.

| Repository | Domain | What the system does |
|---|---|---|
| **[aastf](https://github.com/anonymousAAK/aastf)** ⭐ | AI security | Agentic AI Security Testing Framework. Intercepts the agent execution graph (LangGraph / CrewAI / OpenAI Agents / PydanticAI) and runs 50 attack scenarios mapped to OWASP ASI01–ASI10. 224 passing tests, SARIF output for the GitHub Security tab, EU AI Act readiness reporting. On PyPI: `pip install aastf`. |
| **[aiguard](https://github.com/anonymousAAK/aiguard)** | AI security / Rust | A portable Rust security harness that sits between a CLI coding agent and your machine. Prompt-injection scanning, MCP tool-description auditing, shell/path deny rules, secret redaction, and a TUI session review. One config, eight agents. On crates.io. |
| **[qufin](https://github.com/anonymousAAK/qufin)** | Quantitative finance | Open-source framework for quantum-enhanced quant finance — 159 modules, 11 backends, 4 quantum amplitude estimation variants, 5 error-mitigation strategies. 2,499 tests, 91% coverage. On PyPI: `pip install qufin`. |
| **[plotkit](https://github.com/anonymousAAK/plotrs)** | Languages / systems / Rust | A from-scratch plotting library for Rust with a matplotlib-shaped API — no Python subprocess, no JS runtime, no system deps. 16 chart types, anti-aliased text, PNG/SVG output, optional ndarray/Polars/Jupyter integration. On crates.io as `plotkit`. |
| **[FoldCopilot](https://github.com/anonymousAAK/FoldCopilot)** | Scientific computing | An MCP server that catches confidently-wrong protein-structure predictions. Cross-references AlphaFold3 / Boltz-2 / OpenFold3 / Chai-1 outputs against DisProt/MobiDB ground truth and surfaces backend disagreement — the interpretation layer the field is missing. |
| **[my-DSA-journey](https://github.com/anonymousAAK/my-DSA-journey)** | Algorithms | A 30-week, beginner-to-research curriculum implemented side by side in **Java, Python, C++, and Rust**, with interactive HTML lesson pages per week. DP, network flow, computational geometry, amortized analysis, NP-completeness. |
