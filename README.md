## 👋 The 30-second pitch

I'm **Adarsh** — I build production-grade systems across the full stack and ship them with the rigor of someone who's also stress-tested how they break.

My flagship project, **[AASTF](https://github.com/anonymousAAK/aastf)**, is the first open-source framework that red-teams *the execution graph* of AI agents — not just the model — against the OWASP Agentic-AI Top-10. It's on **PyPI**, ships with **224 passing tests** and **50 attack scenarios**, and has adapters for **LangGraph, CrewAI, OpenAI Agents SDK, and PydanticAI**.

When I'm not breaking agents, I'm building MERN apps, writing my own [programming language](https://github.com/anonymousAAK/adarshLang), or implementing every algorithm in [4 languages at once](https://github.com/anonymousAAK/my-DSA-journey). Currently: PGP @ **IIM Raipur** · BSc Physics (Hons) · published neuromorphic-computing co-author.

### [`aastf`](https://github.com/anonymousAAK/aastf) — Agentic AI Security Testing Framework

> *"84% of production AI agents can be hijacked. AASTF is the first OSS tool that catches it before deployment."*

While every other AI-security tool tests the **model**, AASTF tests the **agent execution graph** — every tool call, every planning step, every multi-agent delegation. It runs **50 attack scenarios** mapped 1:1 to the **OWASP Agentic-Security Initiative Top-10**: Goal Hijack, Tool Misuse, Memory Poisoning, Rogue Agents, Privilege Compromise, and 5 more.

**What's in the box**
- 🔌 Native adapters: **LangGraph · CrewAI · OpenAI Agents · PydanticAI · Generic**
- 📊 **SARIF** output → results land directly in your GitHub Security tab
- 🇪🇺 **EU AI Act** readiness mapping built-in
- ⚙️ **FastAPI** sandbox for isolated agent execution
- ✅ **224 passing tests** across 13 test suites · **4 versioned releases** · **MIT licensed**

